# TIXO CITY

Городской ситуационный центр для Киселёвска. Текущий интерфейс — статический MVP на Leaflet + OpenStreetMap, подключённый к отдельному проекту Supabase.

## Уже работает в проекте

- Карта Киселёвска и ручной запрос геопозиции браузером.
- Каталог камер из `public.cameras` — только записи с `is_public = true`.
- Лента событий из `public.city_events` — только опубликованные записи.
- Справочник источников `public.city_sources` для будущей проверки городских сообщений.
- При пустой базе интерфейс показывает честное пустое состояние, без выдуманных трансляций и событий.

## Supabase

Проект: `TIXO CITY` (регион EU Central).

В `index.html` настроены Project URL и публичный publishable key. Это ключ клиентского доступа, а не секрет администратора. Никогда не помещайте `service_role` key в браузер или GitHub.

Миграция [supabase/schema.sql](supabase/schema.sql) уже применена к проекту. Она добавляет публикацию событий, индексы, триггеры обновления времени и RLS-политики:
- посетители могут читать только записи с `is_public = true`;
- изменять камеры и события могут только авторизованные администраторы с `app_metadata.role = admin`;
- новые события по умолчанию скрыты до проверки и публикации.

Для назначения администратора используйте доверенный Supabase Dashboard / серверную административную процедуру, записывая роль в Auth `app_metadata`. Не используйте `user_metadata`, поскольку пользователь может менять её самостоятельно.

## Развёртывание

Это статический сайт: корень репозитория содержит `index.html`. В Render выберите **New → Static Site**, подключите репозиторий и укажите:
- Build Command: пусто
- Publish Directory: `.`

Если Auto-Deploy включён, Render опубликует изменения после слияния обновления в подключённую ветку.

## Ограничения и безопасность

- Сайт не является экстренной службой и не заменяет официальные источники.
- Не добавляйте закрытые/частные камеры, персональные данные или неподтверждённые сообщения.
- GPS запрашивается только после нажатия пользователем кнопки; координаты не отправляются в Supabase.
- AI-аналитика и мониторинг видеопотоков в реальном времени пока не реализованы.

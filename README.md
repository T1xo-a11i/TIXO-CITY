# TIXO CITY

Городской ситуационный центр для Киселёвска. Текущий интерфейс — статический MVP на Leaflet + OpenStreetMap. Без подключённой базы приложение остаётся в демо-режиме.

## Текущее состояние

- Карта Киселёвска и ручное получение геопозиции браузером.
- Каталог публичных камер и городских событий (пока пустые демонстрационные состояния).
- Подготовлен клиент Supabase; подключение требует URL и публичного anon/publishable key.
- Никакие видеопотоки или AI-анализ не имитируются: в каталоге должны быть только проверенные источники.

## Подключение Supabase

1. Создайте отдельный проект Supabase для TIXO CITY.
2. Откройте SQL Editor и выполните [supabase/schema.sql](supabase/schema.sql).
3. В настройках API проекта скопируйте Project URL и публичный anon/publishable key.
4. Вставьте их в `SUPABASE_URL` и `SUPABASE_ANON_KEY` в `index.html`.
5. Не используйте `service_role` key в браузере и не публикуйте секреты в GitHub.
6. Для администраторов задайте claim в Auth app_metadata: `{ "role": "admin" }`. Не используйте для этого редактируемые пользователем user_metadata.

Схема включает таблицы `cameras` и `city_events`, индексы, автоматическое обновление `updated_at` и RLS. Публичным посетителям доступны только записи с `is_public = true`; создавать, менять и удалять записи могут только авторизованные пользователи с ролью admin в app_metadata.

## Развёртывание

Это статический сайт: корень репозитория содержит `index.html`. В Render выберите **New → Static Site**, подключите этот репозиторий и укажите:
- Build Command: оставить пустым
- Publish Directory: `.`

После изменений в подключённой ветке Render выполнит новый deploy автоматически, если Auto-Deploy включён.

## Ограничения и безопасность

- Сайт не является экстренной службой и не заменяет официальные источники.
- Не добавляйте закрытые/частные камеры, персональные данные или неподтверждённые сообщения.
- GPS запрашивается только после нажатия пользователем кнопки; координаты не отправляются в Supabase.
- AI-аналитика и мониторинг в реальном времени пока не реализованы.
